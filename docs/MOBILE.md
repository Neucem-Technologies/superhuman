# LivinSync mobile

The phone app in [`mobile/`](../mobile/README.md) is the full OS plus HealthKit / Health Connect.

- Shared TypeScript spine with the web app (`src/spine`)
- Native `ios/` HealthKit and `android/` Health Connect
- Tabs: Today, Work, Health, Finance, Businesses, Growth, Travel, Enjoy, Shop, Notes, Files, Connectors

Build on a Mac or Android Studio. The Grok preview remains the web OS.
